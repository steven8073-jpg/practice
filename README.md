# 本機商品管理

不需安裝套件的靜態商品管理網頁。開啟 `index.html` 即可使用。

## 功能

- 新增、編輯、刪除商品；可記錄名稱、商品編號、分類、整數新台幣售價、庫存、說明與上下架狀態。
- 搜尋商品名稱、編號、分類，並依分類或上下架狀態篩選。
- 在列表直接增減或輸入庫存數量；庫存不能小於零。上下架狀態可獨立切換。
- 商品資料儲存在目前瀏覽器的 `localStorage`；可匯出 JSON 備份，或匯入備份覆蓋現有商品。

## 使用提醒

資料只存在目前瀏覽器與其使用者設定檔，清除網站資料或使用其他瀏覽器時不會自動帶入。請定期按「匯出備份」保存 JSON 檔。匯入備份會先詢問確認，確認後取代目前全部商品。
